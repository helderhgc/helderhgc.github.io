AplicativosApps

Ferramentas web gratuitas que implementam métodos desenvolvidos em nossas pesquisas. Free web tools implementing methods developed in our research.

A maioria dos aplicativos está hospedada no Streamlit Community Cloud. Se um aplicativo estiver “adormecido”, clique no botão para ativá-lo; o primeiro acesso pode levar até um minuto. Todos são de acesso livre; quando houver tela de login, é possível entrar como visitante (o cadastro opcional serve apenas para estatísticas de uso). Most apps are hosted on Streamlit Community Cloud. If an app is “asleep”, click the button to wake it up; the first load may take up to a minute. All apps are free to use; where a login screen appears, you can enter as a guest (optional registration is used only for usage statistics).

IntRef

Verifica a integridade das referências bibliográficas de um texto. Cole o texto ou envie um arquivo (PDF, BibTeX ou Word). Cada referência é classificada como validada, não validada ou com problemas de integridade, e o relatório pode ser exportado para Word, PDF ou Excel. Checks the integrity of the bibliographic references in a text. Paste the text or upload a file (PDF, BibTeX or Word). Each reference is classified as validated, not validated or with integrity issues, and the report can be exported to Word, PDF or Excel.
