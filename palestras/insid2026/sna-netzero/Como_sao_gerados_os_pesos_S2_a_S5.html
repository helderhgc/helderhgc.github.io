O S1 (1/3 para cada critério) é a referência: representa a ausência de qualquer informação de preferência.

1S2 · Entropia: pesos tirados dos próprios dados

A ideia: um critério em que os 15 países têm valores parecidos não ajuda a diferenciá-los e deve pesar pouco. Um critério em que os valores se espalham de forma desigual diferencia mais e deve pesar mais. A entropia, conceito da teoria da informação de Shannon (1948), mede justamente o quanto a distribuição é uniforme. O uso da entropia para obter pesos de critérios é um método clássico da decisão multicritério (Zeleny, 1982; Hwang & Yoon, 1981); no artigo, ele é aplicado à matriz normalizada min–máx (Seção 3.4).

Passo a passo, para cada critério j

  1. Normalizar min–máx.
    xij = (gij − mínj) ÷ (máxj − mínj)

    O pior país fica com 0 e o melhor com 1.
  2. Transformar em proporções.
    pij = xij ÷ Σi xij
  3. Calcular a entropia (com 0 · ln 0 = 0).
    Ej = −(1 / ln 15) · Σi pij · ln pij

    Vai de 0 a 1; Ej = 1 significa valores perfeitamente iguais.
  4. Grau de diversificação.
    dj = 1 − Ej

    É o quanto o critério diferencia os países.
  5. Normalizar.
    wj = dj ÷ (d1 + d2 + d3)

O TRL recebe o maior peso porque, depois da normalização, seus valores são os mais desiguais entre os países: é o critério que mais separa os candidatos nos dados.

S2 não expressa a preferência de ninguém

Os pesos de entropia refletem só o poder de discriminação de cada critério naquele conjunto de 15 países. Se a lista de países mudar, os pesos mudam.

2S3, S4 e S5: perfis de política definidos pelos autores

Como nenhum decisor real foi consultado, os autores criaram três perfis “arquetípicos” com duas regras simples:

  • a dimensão priorizada recebe a maior parte do peso;
  • todo critério mantém pelo menos 0,2, para nenhum ser ignorado.

Cenários, ao invés de preferências elicitadas

Os autores deixam claro que esses números não foram obtidos de um decisor. Eles servem para delimitar o espaço de orientações plausíveis, e cada ranking vale para o seu perfil. Numa aplicação real, os pesos viriam do próprio decisor (por pontuação direta, swing weighting ou as ferramentas interativas do PROMETHEE), depois de uma etapa participativa de estruturação do problema.
